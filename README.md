# Queenstown Run Club

Static one-page site for Queenstown Run Club. No build step.

- `index.html` – the page
- `styles.css` – styles
- `assets/web/` – the images and fonts the site actually loads (web-sized copies). The originals sit in `assets/`.
- `app.js` – works out the next run (Wednesday 6:15pm / Friday 6:20am, Queenstown time). Edit the `RUNS` list at the top to change the schedule.

Hosted on GitHub Pages from the `main` branch.
